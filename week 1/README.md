# Week 1: Project Planning

## Project

LearnPulse AI is an early warning system project exploring machine learning methods to identify student disengagement and dropout risk from educational data.

## Objective

Define the problem, project scope, intended outcomes, dataset direction, and implementation plan before model development.

## Activities

- Defined the project problem and objectives.
- Reviewed predictive analytics use cases in education.
- Selected the Open University Learning Analytics Dataset (OULAD) as the initial data source.
- Identified the planned methodology, tools, milestones, and project risks.
- Considered privacy, responsible use, and limitations of student risk predictions.

## Status

Planning documentation is available. Model development and evaluation are planned for later project phases.
