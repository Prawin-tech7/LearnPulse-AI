# LearnPulse AI

LearnPulse AI is a machine learning project focused on predicting student engagement and dropout risk using educational data.

The goal of this project is to identify students who may become disengaged from their courses and provide an early warning mechanism that can support timely intervention.

## Project Objectives

* Analyze student learning behavior
* Identify patterns related to disengagement
* Build predictive machine learning models
* Implement explainable AI techniques
* Deploy the solution using FastAPI
* Evaluate fairness and ethical considerations
